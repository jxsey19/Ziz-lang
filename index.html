À quoi ça ressemble

Des types algébriques, du pattern matching, pas de cérémonie. Le code se lit comme il se pense.

Aperçu de la syntaxe, susceptible de changer avant la sortie.

enum Forme { Cercle(f32), Rect(f32, f32) }

fn aire(f: Forme) -> f32 {
    match f {
        Cercle(r)  => 3.14159 * r * r
        Rect(l, h) => l * h
    }
}

fn main() {
    print("{aire(Rect(3.0, 4.0))}")
}

Ce que Ziz vise

Facile à apprendre
Une syntaxe courte et cohérente, pour écrire son premier programme en une soirée.
Rapide
Ziz compile vers C++ et profite de ses optimiseurs.
Sûr et lisible
Le compilateur attrape les erreurs tôt, et le code reste clair à la relecture.
Fait pour le jeu vidéo et la ligne de commande
Deux terrains où la vitesse et la simplicité comptent le plus.

D’où vient le nom

Le Ziz est un oiseau géant de la tradition talmudique, assez grand pour cacher le soleil avec ses ailes.

Le langage s’inspire de Rust, Go, Zig et OCaml. Son compilateur est écrit en Go.

Ziz est en cours de développement. Suivez le projet sur GitHub.
